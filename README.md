# gletpet
mini games with pyglet

## 3D Bouncing Red Ball

A simple 3D bouncing ball simulation using pyglet and OpenGL.

### Installation

```bash
pip install -r requirements.txt
```

### Usage

```bash
python3 bouncing_ball_3d.py
```

The application will open a window displaying a red ball bouncing in 3D space within a wireframe box.
