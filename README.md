# gletpet
mini games with pyglet

## Games

### Bouncing Ball Game
A simple physics-based game featuring a ball that bounces around the window.

**How to run:**
```bash
# Install dependencies
pip install -r requirements.txt

# Run the game
python bouncing_ball.py
```

**Features:**
- Ball bounces off window boundaries
- Smooth physics simulation
- Simple and clean graphics
- Press ESC to exit
